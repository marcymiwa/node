# NIWA by Marcy Miwa — ヒント小屋（スマホ版）

PC版の ポートフォリオ「NIWA（塔の中の温室）」の まんなかにある **ヒント小屋の中身** を、スマホの 1 画面に したもの。

- 上: 温室の 格子の ドーム、かべの とびら ①〜⑤、ヒント小屋と まーしー（ぜんぶ SVG で 描くので 画像を 読まない）
- 下: MOTHER2 風の **マーシーの窓**。PC版と おなじ ことば・おなじ ながれ

```
はなす → やっほー！（はじめて なら 自己紹介）→ ひとこと
  └ あそびかた / へやのこと / さくひん / まーしーのこと / またね
      へやのこと → ① 解築停留所 … → つれていって → いってらっしゃい！ → へやの なか
      とびらを タップ → 「① 解築停留所の とびらだ。… はいる？」
      まーしーのこと → 3 ページ → れんらく（メール・Instagram）
      またね → へやを みる前は「またね！」で とじる / みたあとは おわかれ と いちらん
```

## ひらきかた

ビルドは いらない（ふつうの HTML / CSS / JS）。フォルダを そのまま 静的サーバで 出せば うごく。

```sh
npx serve .            # または python3 -m http.server
# → http://localhost:3000/ を スマホの 幅で ひらく
```

- `?lang=en` … 英語で ひらく（右上の JA / EN でも かわる。えらんだ ことばは おぼえておく）
- `?time=21:00` … 時間帯の 空を ためす（ふだんは 見ている人の 時計: 朝・昼・夕方・夜）

GitHub Pages なら、Settings → Pages で このブランチ（または main）の ルートを えらぶだけ。

## 作品を 足す・なおす

1. `assets/js/content.js` の `WORKS` に 1 つ 足す（`room` に へやの id）
2. `ROOMS` の その へやの `works` に id を 入れる
3. `node tools/build-list.mjs`（もじだけの ページを つくりなおす）
4. `node tests/mobile-check.mjs`（はみ出し・16px より 小さい字・エラーが ないか）

PC版の 3D の温室を 公開したら、`SITE.pcUrl` に URL を 入れると「3D の温室へ」の ボタンが 出る。
ポートフォリオの PDF が できたら `SITE.contact.pdf` に 入れると、またね の あとと いちらんに PDF が 出る（PC版と おなじ）。

## きまり

- 字は 16px 以上（PC版の mobile_check と おなじ）。押せる ものは 44px 以上
- 「うごきを へらす」設定の 人には、文字おくり・ゆれ・光の粒を 止める
- 画面に 出る ことばは PC版の 原文の まま。スマホに あわせて 書いたのは「あそびかた」だけ（PC版は キーボードの 説明のため）
